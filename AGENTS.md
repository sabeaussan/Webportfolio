# Repository Guidelines

## Project Goal

The goal of the project is to build a personnal website using the Astro/Github pages stack. The structure of the project should be modular and easily extensible, and well detailed in the README.md file.

## Specifications
It should contains:
- An "about me" page.
- A notes section with multiple pages.
- A projects section with multiple pages.

The strongest visual characteristics are:

- Vintage robot design — boxy body, antennas, lenses, knobs and exposed mechanical joints. Very much the pre-digital idea of a robot.
- Limited print palette — cream, coral/red-orange, dark navy and desaturated blue/teal.
- Heavy ink outlines — almost comic-book or screen-print-like.
- Off-white rather than pure white — gives everything a printed, slightly aged character.
- Geometric landscapes — angular mountains and simplified planetary forms.
- Mid-century composition — large graphic shapes rather than photorealistic detail.
- Analog technology aesthetic — dials, switches, antennas and mechanical controls instead of glowing holographic interfaces.
